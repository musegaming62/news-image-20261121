# Sum up 21 November's world news in one image

A dense newspaper front page that sums up the world's news of Saturday 21 November 2026 in a single 1024x1024 image, for the make.fun competition [news-image-20261121](https://make.fun/bounty/news-image-20261121).

The image is generated by `main.py` (deterministic, stdlib only): a dark-navy masthead naming the day, hero cards for the day's biggest stories, and a dense grid of numbered stories across regions and topics, each with a short label, verification tag and source. A date-check footer lists only stories whose EVENT happened on 21 November 2026 (verified against primary sources by event date, not article date).
